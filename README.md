🚗 FahrbahnApp

Modern multilingual platform for German driving theory preparation.

----------------------------------------

✨ Features

- 🇩🇪 German driving theory learning
- 📝 Official exam simulation
- ❤️ Favorite questions
- ❌ Wrong answers notebook
- 📊 Dashboard & statistics
- 🎙️ Text-to-Speech
- 🤖 AI-powered explanations
- 🌍 Multilingual (Persian / English / German)
- 📱 Responsive design
- 🎯 Progress tracking

----------------------------------------

🛠️ Tech Stack

- Django
- Python
- SQLite
- Tailwind CSS
- DaisyUI
- JavaScript
- django-modeltranslation
- Django i18n
- Google Gemini API
